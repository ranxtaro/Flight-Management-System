# Практична робота №1 з дисципліни «Об'єктно-орієнтоване програмування».

## Тема

**Класи та об'єкти**

## Опис проєкту

Програма являє собою невелику систему керування авіарейсами аеропорту.

Користувач може створювати об'єкти класу `Flight`, переглядати інформацію про рейси, виконувати пошук, змінювати стан рейсу за допомогою методів класу та видаляти об'єкти.

Графічний інтерфейс реалізований за допомогою **WinUI 3**.

## Використані технології

- C#
- .NET
- WinUI 3
- Visual Studio
- GitHub

## Клас Flight

Основним класом програми є `Flight`, який описує авіарейс.

### Характеристики

- `FlightNumber` - номер рейсу;
- `Destination` - місто призначення;
- `DepartureTime` - дата та час вильоту;
- `PassengerCount` - кількість пасажирів;
- `TicketPrice` - вартість квитка;
- `Status` - поточний статус рейсу;
- `IsInternational` - ознака міжнародного рейсу.

Для поля `Status` використовується перелічуваний тип `FlightStatus`.

### FlightStatus

Можливі значення:

- `Scheduled`
- `Boarding`
- `Delayed`
- `Departed`
- `Cancelled`
- `Landed`

## Методи класу

Клас `Flight` містить методи, які описують поведінку об'єкта:

- `AddPassenger()` - додає одного пасажира;
- `DelayFlight(int minutes)` - переносить час вильоту та встановлює статус `Delayed`;
- `StartBoarding()` - починає посадку пасажирів;
- `CancelFlight()` - скасовує рейс.

## Основні можливості програми

Програма дозволяє:

- задавати максимальну кількість об'єктів `Flight`;
- додавати нові рейси;
- переглядати всі створені рейси у вигляді таблиці;
- переглядати детальну інформацію про обраний рейс;
- шукати рейси за номером рейсу;
- шукати рейси за містом призначення;
- виконувати методи класу `Flight`;
- видаляти рейс за його порядковим номером;
- видаляти рейси за характеристикою;
- завершувати роботу програми за допомогою кнопки `Exit`.

## Перевірка введених даних

Перед створенням об'єкта програма перевіряє введені користувачем дані.

Основні обмеження:

- номер рейсу повинен містити від 2 до 7 символів;
- номер рейсу може містити тільки латинські літери та цифри;
- місто призначення не може бути порожнім;
- місто призначення може містити тільки літери та пробіли;
- дата і час вильоту повинні бути в майбутньому;
- кількість пасажирів повинна бути цілим числом від 0 до 500;
- вартість квитка повинна бути більшою за 0 та не перевищувати 10000;
- максимальна кількість рейсів повинна бути додатним цілим числом.
